## 结论与边界

- offline 模式是确定性规则路由，准确率 100% 说明评测集被路由规则覆盖，**不代表泛化能力**；
  真实泛化能力以 llm 模式（配置 API key 后）的准确率为准，评测脚本同一套。
- 数字溯源通过率 100%：所有回答中的数字都能在工具返回或派生值池中找到来源（容差 0.5%）。
  该护栏在开发期真实抓到过 3 次问题（日期误识别为数字、供应商编号误识别、派生均值未登记），均已修复。
